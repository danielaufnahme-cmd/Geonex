Today I continued working on the Geonex parser after finishing the first version of the lexer.

The lexer can now recognize the basic values and types needed for the language, including integers, floats, strings, and booleans. It can also recognize some basic language constructs, including the foundations needed for if statements and other basic syntax.

For now, I'm keeping the language relatively simple. I haven't implemented classes, and I'm still not completely sure whether I want to add them in the future. Functions, however, are definitely planned.

For functions, I want Geonex to use explicit return types. The function declaration will specify what type the function returns. I still need to decide on the exact syntax for function declarations.

Today I'm planning to finish the parser. If I still have enough energy afterward, I might start working on the AST (Abstract Syntax Tree). We'll see how tired I am.

The parser can already recognize basic variable declarations such as:

int age = 14;
string name = "Daniel";

Overall, I'm really happy with how Geonex is developing. The lexer and parser are starting to make the language feel like an actual programming language rather than just an idea.

There were some bugs along the way, which I had to fix. I also used AI-generated code occasionally for small parts that would otherwise have taken me a few hours to figure out. However, I wrote most of the implementation myself and mainly used AI as a tool when I got stuck.

The project is progressing well, and I'm looking forward to seeing how Geonex develops once the parser and AST are finished.
